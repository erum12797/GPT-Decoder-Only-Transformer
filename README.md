# GPT Decoder-Only Transformer

## Project Overview
This project implements a small GPT-style Decoder-only Transformer using PyTorch.

The model is trained from scratch to learn next-token prediction.

## Architecture
- Token Embedding
- Positional Embedding
- Masked Self-Attention
- Query, Key and Value (Q, K, V)
- Feed Forward Network
- Linear Output Layer
- Softmax

## Technologies
- Python
- PyTorch
- Google Colab
- GitHub
- Vercel

## Training
The model is trained using a small educational text dataset.

## Objective
To understand Transformer architecture and demonstrate next-token prediction.

## Deployment
The frontend will be deployed using Vercel, with a separately hosted model API.
